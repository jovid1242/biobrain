## 3. OBSERVED RESULTS

1. **Движок корректен в пределах проверок.** 108 тестов проходят. На реальных подграфах растры двух режимов
   идентичны в 80 из 80 сравнений, число спайков совпадает в 220 из 220 пар бенчмарков. В float64 режимы
   совпадают на 40,000 шагах (2.8 млн спайков). В float32 длинный прогон time-step расходится с эталоном с шага
   3,349, event-driven — нет.
2. **Окно устойчивости есть у 6 из 7 подграфов** (DEAD → STABLE → SATURATED по gain). neuropil_PB мёртв при
   любом gain, если глутамат тормозной, и получает окно, если возбуждающий. На baseline 10k и 50k после входа
   поддерживают активность сами.
3. **Event-driven быстрее time-step только при очень редкой активности:** ≲ 0.015–0.12 приходящих событий на
   нейрон за шаг, ≳ 93–99 % пропущенных обновлений. Лучшее ускорение — 6.6× (100), 3.0× (1k), 1.22× (10k). С
   ростом сети перелом сдвигается к меньшей активности, на 50k его нет вовсе. На нейропиле LO_R перелома нет,
   на SPS_R он при входе 0.003–0.005 %. Из паттернов входа быстрее только pulse на 1k (1.14×).
4. **При входе 1 % (12–19 Гц на нейрон) event-driven медленнее в 2.5–13 раз.**
5. **Время определяют синапсы.** В time-step выборка исходящих рёбер и доставка занимают 54–94 % шага при входе
   ≥ 0.1 %. В event-driven — сортировка событий (до 83 %) и ленивая утечка (до 67 %).
6. **Память не ограничение.** Состояние нейрона — 8 байт (TS) или 12 байт (ED). Максимальный процесс — 507 MiB на 50k.
7. **Динамика сильно зависит от допущений:** знак глутамата, преобразование весов, порог по числу синапсов.
   Умеренно — τm и gain, слабо — остальное.
8. **Оценка энергии ОС** (6.6–7.8 Дж на секунду CPU) повторяет время CPU: ED/TS 0.67 / 5.72 / 2.92 по энергии
   против 0.76 / 5.94 / 3.02 по времени.

## 4. INTERPRETATION

- Инфраструктура для экспериментов с реальной топологией готова и проверена. Биологическая адекватность модели —
  нет: веса, знаки и константы ASSUMED.
- **Отрицательный результат для этой реализации:** на CPU с NumPy event-driven исполнение не даёт преимущества
  при активности, которую эта модель показывает при умеренном входе. Причина измерена: стоимость — синаптические
  события, одинаковые в обоих режимах, а «пропускаемые» обновления нейронов в NumPy почти бесплатны. Это не
  опровергает event-driven подход вообще. В компилируемом коде без сортировки и аллокаций на шаг перелом может
  сдвинуться — гипотеза, не измерено (`PERFORMANCE_PLAN.md`).
- Плотные подграфы (100–200 событий на спайк) и самоподдерживающаяся активность больших подграфов работают
  против разреженного исполнения. Более разреженный нейропиль SPS_R ведёт себя как 1k: перелом при
  0.003–0.005 % входа.
- Гипотеза «≈ 10× меньше вычислений» в M2 **не подтверждена и не опровергнута**: задач и обучения ещё нет, а
  энергия не измерялась.

## 5. LIMITATIONS

Полный список — `docs/M2_LIMITATIONS.md`. Главное:

- Current-based LIF без нижней границы потенциала, одна задержка, никакой нейромодуляции как процесса.
- Все параметры, кроме числа синапсов и медиатора, ASSUMED. Gain калиброван отдельно для каждого подграфа.
- Жадное расширение выбирает плотные ядра: 35–177 рёбер на нейрон против 108 в среднем по мозгу.
- Производительность относится только к Python + NumPy на одном ядре Apple M5 без вентилятора, от батареи.
- Эквивалентность float32 проверена только на коротких горизонтах, на длинных она нарушается.
- 50k: 2 seed, 300 шагов. Нейропили: 1 seed. Длинная эквивалентность: один подграф, один seed.
- Энергия не измерялась. Полный мозг не симулировался.
