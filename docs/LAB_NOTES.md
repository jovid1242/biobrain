# Научный журнал

Формат записи: DATE · HYPOTHESIS · SETUP · RESULT · INTERPRETATION · PROBLEMS · NEXT.
RESULT — только то, что измерено или прочитано в источнике. INTERPRETATION — наше понимание, может оказаться неверным.

## LN-001 · 2026-09-16 · Исследование источников

**HYPOTHESIS.** FlyWire FAFB 783 остаётся лучшей стартовой точкой для графового исследования; существуют
первичные числа, с которыми можно сверить собственную обработку.

**SETUP.** Три независимых прохода по первоисточникам (flywire.ai, Codex, Zenodo API, GitHub API, Nature/Cell/
bioRxiv/arXiv, neuPrint/Janelia): (A) продукты данных FlyWire и их статистика; (B) все доступные коннектомы
дрозофилы; (C) предшествующие работы по коннектому как архитектуре. Требование — дословная цитата + URL на каждое
число. Выборочная ручная перепроверка: Zenodo API (файлы, размеры, md5, лицензия, версии записи), GitHub API
(теги, blob SHA), цитаты Dorkenwald/Schlegel в сохранённых текстах, arXiv API для пяти работ 2025–2026.

**RESULT.**
- 783 — последний публичный релиз FAFB (flywire.ai, Codex). Запись Zenodo 10676866 существует в единственной
  версии (783.0, 2024-06-02), 5 файлов, 10.6 GB, лицензия CC BY 4.0; flywire.ai указывает CC BY-NC 4.0.
- После 783 изменились аннотации (v3.1.0, 2026-07-21) и появился альтернативный набор синапсов (Princeton,
  preprint 2025, в Codex по умолчанию с июля 2025).
- Опубликованные суммы расходятся на уровне десятков тысяч синапсов и ~1,000 связей между источниками (таблица в `RESEARCH.md` §9).
- Счёт суперклассов в Schlegel 2024 суммируется в 127,864, а не в 139,255.
- В литературе преимущество топологии коннектома против degree-preserving null-моделей обычно исчезало или
  было небольшим; самый сильный позитив — FlyGM (2026, RL-контроллер тела), без описанного контроля общей инициализации.

**INTERPRETATION.** Выбор FAFB 783 + синапсы Buhmann обоснован воспроизводимостью и возможностью сверки.
Сумма 127,864 указывает на то, что счёт в статье сделан по более раннему снимку (вероятно, 630) — это надо
учитывать при валидации. Априорная вероятность «чистого» выигрыша H1 невысока — это аргумент за строгий протокол, а не против проекта.

> **ПОПРАВКА (2026-09-17, см. LN-003).** Объяснение «более ранний снимок» оказалось **неверным**. На аннотациях
> v2.1.0 все числа статьи совпали точно; 11,391 «недостающих» нейронов — зрительные сенсорные, которых фраза
> статьи просто не перечисляет. Запись оставлена как есть, чтобы ошибка была видна.

**PROBLEMS.** Часть полных текстов закрыта (Cell, ScienceDirect, bioRxiv rate limit); использованы зеркала
(Europe PMC, PMC, arXiv) — помечено. Codex-портал и CAVE требуют логина и не проверялись.

**NEXT.** Скачать минимальный набор, проверить эти числа на данных.

## LN-002 · 2026-09-16 · Загрузка данных: сбой Zenodo

**HYPOTHESIS.** Шесть файлов (~1.1 GiB) скачиваются скриптом и совпадают с официальными checksum.

**SETUP.** `biobrain download` (каталог `catalog/flywire_fafb_v783.toml`).

**RESULT.**
- GitHub: обе версии аннотаций скачаны, git blob SHA-1 совпали с GitHub API (v3.1.0: 31,718,505 байт; v2.1.0: 27,015,208).
- Zenodo: с ~21:40 (UTC+5) все запросы к файлам — HTTP 504 Gateway Time-out через ~30 с; позже 504 отдавали
  и API записей, и главная страница zenodo.org перестала отвечать. Сбой на стороне Zenodo, не зависит от записи.
- v3.1.0 содержит **139,248** строк при 139,255 нейронах; v2.1.0 — 139,255.

**INTERPRETATION.** Первая версия загрузчика останавливалась на первом сбойном файле и буферизовала лог —
исправлено: повторы с докачкой, изоляция ошибок по файлам, построчный лог. Публичный bucket Codex мог бы
заменить Zenodo, но это другой формат (без 6 вероятностей нейромедиатора и без счётчиков по neuropil) и
недокументированный путь — без решения владельца не используется (D-011).

**PROBLEMS.** Пока Zenodo недоступен, preprocess/validate/analyze на реальных данных не выполнены.
Весь код проверен на синтетических релизах того же формата (48 тестов).

**NEXT.** Дождаться Zenodo (фоновые повторы), затем preprocess → validate → analyze → bench-memory; выяснить, каких 7 нейронов нет в v3.1.0.

## LN-003 · 2026-09-17 · Аннотации: две версии против статьи

**HYPOTHESIS.** (а) Счёт суперклассов в Schlegel 2024 описывает не релиз 783 (моё вчерашнее объяснение суммы 127,864).
(б) v3.1.0 отличается от v2.1.0 только на 7 нейронов.

**SETUP.** Обе TSV (проверены по git blob SHA-1) против `proofread_root_ids_783.npy` (проверен по md5). Отдельный скрипт; формально повторяется в `biobrain validate` (H1–H4, G1–G5).

**RESULT.**
- v2.1.0: 139,255 строк, множество root id **совпадает** со списком 783. Суперклассы: optic 77,536; central 32,388; sensory 16,903; visual_projection 8,053; ascending 2,362; descending 1,303; visual_centrifugal 524; motor 106; endocrine 80.
- sensory = 11,391 (cell_class `visual`) + **5,512** незрительных — ровно число статьи; остальные 8 классов совпадают со статьёй точно.
- Типы: `cell_type` — 5,634 значения (79.8 % нейронов); «`cell_type`, иначе `hemibrain_type`» — **8,453** значения (число статьи точно), покрытие 94.65 % (в статье 96.4 %).
- v3.1.0: 139,248 строк; **7** root id нет в списке 783; у **14** нейронов из списка 783 нет строки (по v2.1.0: 1 центральный CX, 3 механосенсорных JO-B, 10 оптических). Суперкласс изменился у 639 общих нейронов (612 из них: ascending → новый `sensory_ascending`), cell_type — у 47,612.
- Чтение v2.1.0 падало: `nucleus_id` и `soma_x` записаны как `2453924.0`. Исправлено: целочисленные id читаются из текста (точно и для значений > 2⁵³).

**INTERPRETATION.** Гипотеза (а) опровергнута: статья описывает именно 783, просто формулировка неполная.
Гипотеза (б) неверна: разница больше (7 заменённых/новых id + 14 без строки) и типизация сильно переработана.
v3.1.0 остаётся рабочей версией (больше типов, 98.9 % нейронов с `cell_type`), но 14 нейронов получают пустые
аннотации, а сравнения со статьями делаются только на v2.1.0.

**PROBLEMS.** Что стоит за 7 новыми id (переразбиение сегментов после 783?), без CAVE не проверить. Знаменатель 96.4 % не найден.

## LN-004 · 2026-09-17 · Валидация графа на реальных данных

**HYPOTHESIS.** Наш конвейер воспроизводит все опубликованные итоги FlyWire 783 без подгонки; инварианты хранилища выполняются.

**SETUP.** `biobrain preprocess` → `biobrain validate` (commit `d47ea8e`). 54 проверки: инварианты, числа из
статей и Codex с указанием источника, независимый пересчёт итогов через Arrow `group_by`.

**RESULT.**
- Первый прогон: 29 PASS, **3 FAIL**, 8 WARN. Разбор показал **две ошибки обработки** и одну ложную проверку:
  1. релиз обозначает «нет neuropil» строками `UNASGD` (таблица связей) и `"None"` (счётчики); код считал их регионами → 79 «neuropil» вместо 78 и несовпадения итогов с Codex;
  2. у 1,732 строк все шесть вероятностей нейромедиатора — NaN; код занижал вероятности у 481 ребра, деля на все синапсы, включая непредсказанные;
  3. проверка «сумма вероятностей = 1» не учитывала рёбра без предсказаний.
- После исправлений (с тестами на синтетических данных с теми же аномалиями): **38 PASS, 0 FAIL, 3 WARN, 13 INFO**.
- Точно воспроизведены: 139,255 нейронов; 16,847,997 строк; 15,091,983 пары; 54,492,922 синапса; 2,700,513 пар ≥ 5 между 134,181 нейронами; 130,054,535 / 130,038,118 / 121,904,312 / 58,096,025 синапсов (Zenodo/Codex); 78 neuropil; суперклассы и 8,453 типа Schlegel 2024.
- Self-connections: 0. Изолированных нейронов: 616. Медианная доля пресинапсов нейрона с proofread-партнёром: 52 %.

**INTERPRETATION.** Данные в store совпадают с первоисточниками до синапса. Главный урок: «скрипт завершился
без ошибки» ничего не значил. Обе ошибки давали правдоподобные числа и были пойманы только сверкой с
независимыми итогами. Число 2,701,601 у Lin 2024 для 783 наши данные не подтверждают (подтверждают 2,700,513 Dorkenwald 2024).
Граф заметно неполон со стороны выходов нейронов: это ограничение для любой модели на его основе.

**PROBLEMS.** Остались 3 WARN, не зависящие от нас (annotation drift v3.1.0, знаменатель 96.4 %).

**NEXT.** Замеры памяти; анализ графа.

## LN-005 · 2026-09-17 · Представления графа: память против скорости

**HYPOTHESIS.** Компактное представление (CSR) достаточно; сжатие (varint, квантование) даст выигрыш по памяти без существенной потери скорости.

**SETUP.** `biobrain bench-memory` (commit `d47ea8e`): 13 представлений, каждое в отдельном процессе. Первый прогон
дал завышенный RSS: в него попадали страницы memmap-источника и временные массивы тестов доступа. Методика
исправлена (RSS сразу после построения, источники без memmap), прогон повторён.

**RESULT.** Байт на ребро: Python-объекты 128–256 (экстраполяция), Arrow «как скачано» 90.7, COO int64 24,
COO compact 10, **CSR 6.07 (87 MiB на весь мозг)**, CSR+CSC 14.15, delta+varint 3.02, zstd 3.29, region-local ids 5.20.
Шаг спайков (1 % нейронов, 143,676 событий): CSR 0.51 мс, COO 10.7–15.7 мс, varint 3.27 мс. Полный проход: CSR 25 мс, varint 369 мс.
Веса: uint16 без потерь (максимум 2,405); uint8-лог ошибается ≤ 7.1 % на ребро.

**INTERPRETATION.** Гипотеза частично опровергнута: сжатие вдвое (varint) стоит 6.4× по шагу спайков и 15× по
полному проходу, и при графе в 87 MiB это невыгодно. Region-local ids дают только −14 %, потому что лишь 47.6 %
рёбер лежат внутри home neuropil. Узкое место для 8 GB будет не граф, а рабочая память и состояния модели.

**PROBLEMS.** Скорости измерены в NumPy из Python; это сравнение представлений, а не производительность будущего симулятора.

## LN-006 · 2026-09-17 · Структура графа против null-моделей

**HYPOTHESIS.** (а) Анализатор на релизе 783 воспроизводит сетевую статистику Lin et al. 2024 (релиз 630).
(б) Граф мухи отличается от degree-preserving random не только распределением степеней.

**SETUP.** `biobrain analyze` (commit `063d2be`, seed 20260916, 2,150 с, peak RSS 3.05 GiB): графы ≥ 1 и ≥ 5
синапсов; ER и 5 degree-preserving null-моделей; triad census; Leiden; rich club; sampled betweenness; cost gate
на каждом дорогом шаге.

**RESULT.** (полностью — `docs/RESULTS.md`)
- ≥ 5: reciprocity 0.1398 (null ×45.8), clustering 0.0448 (null ×7.95), путь 4.45, S^Δ 156, медиана степеней intrinsic 11/13, Pearson 0.757.
- Мотивы: открытые цепочки ×0.51–0.66 от null; 030T ×4.6; 030C ×1.75; взаимные тройки ×10–520.
- Leiden Q 0.712 (без весов 0.698 против 0.126 у null).
- Rich club: ≤ +3.2 % при степени 24–91, ниже null при степени ≥ 102.
- Betweenness: top-100 двух выборок пересекаются на 50 %.
- Оценщик triad census ошибся в 3.2–4.4 раза в меньшую сторону.

**INTERPRETATION.** (а) Подтверждено: совпадение с Lin по порядку и часто до второго знака. (б) Подтверждено:
reciprocity, clustering, модульность и замкнутые мотивы далеко за пределами degree-preserving null. Для M4 это
означает, что контроль «перемешанная муха» должен быть лестницей null-моделей, а не одной моделью. Rich club
как «существенное свойство» данными **не поддержан**. Betweenness на отдельных нейронах при 256 источниках —
не результат.

**PROBLEMS.** Калибровка стоимости на ER не переносится на тяжёлые хвосты. 5 null-выборок мало для редких мотивов.
Triad census на графе ≥ 1 не посчитан.
