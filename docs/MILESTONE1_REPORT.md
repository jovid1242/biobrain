## Important discoveries

1. **Данные совпадают с первоисточниками до синапса**, но только после двух исправлений, которых без сверки не было бы видно:
   - «нет neuropil» в релизе записан строками `UNASGD` и `"None"`;
   - у 1,732 строк нет предсказания нейромедиатора (NaN): код занижал вероятности у 481 ребра.
2. **Выходы нейронов в графе недоучтены примерно вдвое.** У медианного нейрона лишь 52 % пресинапсов ведут к
   proofread-партнёрам, потому что постсинапсы прикреплены на 44.7 %.
3. **Половина пар — один синапс**, но пары ≥ 5 синапсов (17.9 %) несут 62.7 % всех синапсов.
4. **Граф сильно рекуррентен и модулярен.** Reciprocity, clustering, модульность и замкнутые мотивы далеко за
   пределами degree-preserving null. Значит, контроль «перемешанная муха» для H1 должен быть лестницей
   null-моделей, а не одной моделью.
5. **Утверждение «у мухи есть rich club» данными не поддержано:** есть лишь слабое обогащение на средних
   степенях, у крупных хабов картина противоположная.
6. **Литература против нашей надежды:** в известных работах преимущество коннектома против строгих null-моделей
   обычно исчезало. Прямой проверки H1 на FlyWire с SNN и мультизадачным бенчмарком нет, ответ открыт.
7. **Моя ошибка, найдена и исправлена:** гипотезу «счёт суперклассов в статье — по старому снимку» опровергли
   сами данные. Статья описывает 783, а 11,391 «недостающий» нейрон — зрительные сенсорные.
8. **Self-connections в proofread-таблице нет.** Число 2,701,601 у Lin для 783 не воспроизводится, а 2,700,513 Dorkenwald воспроизводится.

## Problems

- **Zenodo был недоступен** около 1.5 часа (HTTP 504 на всё). Загрузчик стал устойчивее: докачка, повторы,
  параллельные файлы, изоляция ошибок.
- **Аннотации v3.1.0:** 7 root id вне списка 783, 14 нейронов без строки. Причина не установлена.
  Покрытие типами 94.65 % против 96.4 % в статье: знаменатель статьи не найден.
- **Оценщик стоимости triad census ошибся в 3–4 раза** на графе с тяжёлыми хвостами. Triad census для графа ≥ 1
  не посчитан, лимит превышен.
- **Betweenness при 256 источниках** не даёт устойчивого ранжирования отдельных нейронов.
- **Null-выборок 5** (у Lin 100): для редких мотивов точность около ±10 %.
- **Первый прогон memory benchmark** завышал RSS; методика исправлена и прогон повторён.
- **Скорости — в NumPy из Python:** это сравнение представлений, не производительность симулятора.
- **Не сделано в M1 (не входило в список):** визуальный UI (есть CLI `biobrain neuron`) и `PRUNING_PLAN.md`
  (нужен разбор функций регионов по литературе).

## Assumptions (`docs/ASSUMPTIONS.md`)

- Ребро — пара (pre, post), вес — сумма синапсов по neuropil. Вероятности нейромедиатора ребра —
  средневзвешенное по строкам с предсказанием, uint8.
- Self-connections хранятся, но исключаются из статистики (в 783 их 0).
- Home neuropil — neuropil с максимумом пресинапсов (правило Lin).
- Clustering — на неориентированном представлении.
- Пути, betweenness и null-модели — выборки с указанным размером.
- **Допущений модели нейронов пока нет:** веса, знаки, пороги, задержки, gap junctions и нейромодуляция —
  открытые вопросы Milestone 2.

## Recommended Milestone 2

1. **Минимальный LIF-симулятор на CSR (NumPy).** Состояние нейрона ~16 байт; вес = число синапсов × знак.
   Знак — по top_nt нейрона; правило для глутамата и модуляторов — явное допущение с проверкой чувствительности.
2. **Лестница размеров:** 100 → 1k → 10k нейронов. Подграфы — связные: сообщество Leiden или neuropil, а не
   случайная выборка, иначе связей почти не останется. Метрики: спайки, synaptic operations, стабильность
   (не насыщается и не затухает), RAM, время.
3. **Event-driven против time-step — бенчмарком** на одной и той же модели и одних и тех же входах.
4. **Первые null-графы для M4 заранее:** degree-preserving и reciprocity-preserving на том же подграфе. Это
   позволит сразу проверить, что симулятор отличает структуры.
5. **Исправить калибровку стоимости** на графах с тяжёлыми хвостами до следующих дорогих анализов.
