# Журнал решений

Формат: решение → почему → отвергнутые альтернативы → последствия. Новое решение не переписывает старое, а
ссылается на него («заменяет D-00x»).

## D-001 · 2026-09-16 · Отдельный проект `~/biobrain`
**Решение:** BioBrain живёт в собственной папке и собственном git-репозитории, рядом с `~/siliconfly`.
**Почему:** SiliconFly — публичный репозиторий с собственным `data/` (95 MB, свой ETL на стороннем parquet);
смешивание сломало бы оба проекта. SiliconFly не изменён (проверено `git status`: clean).
**Последствия:** данные SiliconFly не переиспользуются; BioBrain качает всё из первоисточников сам.

## D-002 · 2026-09-16 · Dataset: FlyWire FAFB 783, синапсы Buhmann, Zenodo 10676866
**Решение:** основной граф — `proofread_connections_783.feather` + `proofread_root_ids_783.npy` с Zenodo.
**Почему:** 783 — последний публичный релиз FAFB (flywire.ai, Codex); единственный путь без логина, с DOI и
официальными md5; именно эти данные описаны в peer-reviewed статьях (Dorkenwald 2024, Schlegel 2024, Lin 2024) →
есть с чем сверять. Обоснование и сравнение датасетов — `docs/RESEARCH.md`.
**Отвергнуто:** Princeton synapses (preprint, логин, лицензия данных не указана) — позже как проверка
устойчивости; male CNS / BANC — позже для репликации на другой особи; SiliconFly parquet — не первоисточник.

## D-003 · 2026-09-16 · Версии аннотаций
**Решение:** анализ — flywire_annotations `v3.1.0` (commit `8587524c`); валидация против статей — `v2.1.0` (commit `ebd66db2`).
Обе закреплены по SHA коммита и git blob SHA-1.
**Почему:** v3.1.0 — самая свежая систематическая версия; числа статей 2024 года соответствуют более ранней.
**Последствия:** расхождения между версиями фиксируются как annotation drift (см. `results/data_validation.md`).

## D-004 · 2026-09-16 · Что не скачиваем
**Решение:** не качаем `flywire_synapses_783.feather` (9.49 GB), Codex-продукты, Princeton synapses, skeletons,
meshes, EM-изображения. Таблица синапсов есть в каталоге как `optional` + `large` (только с `--allow-large`).
**Почему:** граф строится из агрегированных `syn_count`; координаты и cleft score отдельных синапсов нужны
только для ре-порогования и пространственных моделей — не в Milestone 1.

## D-005 · 2026-09-16 · Лицензия данных
**Решение:** считаем данные FlyWire CC BY-NC 4.0 (строже из двух указанных: Zenodo — CC BY 4.0, flywire.ai — CC BY-NC 4.0);
данные никогда не коммитятся; в README — требования цитирования.

## D-006 · 2026-09-16 · Стек: Python + NumPy/SciPy/PyArrow/igraph в локальном venv
**Решение:** `.venv` в проекте, точные версии — `requirements.lock`; pandas не используется.
**Почему:** компактные numpy-массивы и memmap; SciPy — CSR и компоненты; PyArrow читает Feather/CSV официальных
релизов; igraph — C-ядро для triad census, Leiden, betweenness, rewiring без Python-объектов на ребро.
Системный Python не изменён.

## D-007 · 2026-09-16 · Processed store = `.npy` + `manifest.json`, CSR + CSC
**Решение:** CSR исходящих рёбер + CSC входящих с перестановкой `in_edge` (атрибуты ребра хранятся один раз),
разбивка по neuropil на уровне строк, вероятности нейромедиатора в uint8.
**Почему:** memmap без парсинга, O(1) доступ к соседям в обе стороны, проверяемые sha256.
Сравнение с альтернативами (COO, varint, zstd, объекты) — `docs/MEMORY.md`, решение пересматривается по его итогам.

## D-009 · 2026-09-16 · Контроль стоимости анализа
**Решение:** дорогие шаги проходят через cost gate (калибровка на этой машине / пилот; лимит по умолчанию 900 с на шаг),
решение и фактическое время публикуются. Точный all-pairs и точная betweenness не считаются.

## D-010 · 2026-09-16 · Бюджет памяти
**Решение:** `--memory-budget` (по умолчанию 8 GiB, строгий режим): проверка перед тяжёлой аллокацией → `MemoryBudgetExceeded`
с объяснением; в каждом отчёте — peak RSS.

## D-011 · 2026-09-16 · Загрузчик при сбое Zenodo
**Контекст:** во время первой загрузки Zenodo отвечал HTTP 504 на все файлы и даже на API записи.
**Решение:** повторы с экспоненциальной паузой (до 60 с), докачка через HTTP Range, ошибка одного файла не
останавливает остальные, итоговый список сбоев. Недокументированный публичный bucket Codex как запасной путь
**не используется без решения владельца проекта** (другой формат, нет 6 вероятностей нейромедиатора и счётчиков
по neuropil; Codex рекомендует документированный путь с логином).
