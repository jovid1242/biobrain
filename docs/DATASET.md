## 5. Что нашлось в данных (важно для всех следующих этапов)

1. **«Не назначенный neuropil» записан строками.** В таблице связей это `UNASGD` (3,193 строки, 4,185 синапсов),
   в файлах счётчиков — строка `"None"` (16,417 синапсов). В store обе метки превращаются в пустой код.
   В документации Zenodo этого нет.
2. **Нет предсказания нейромедиатора у 1,732 строк** (все 6 вероятностей NaN; 30,806 синапсов). У 1,251 ребра
   предсказаний нет совсем (в store это нули), у 481 ребра они частичные. Причина в документации не указана.
3. **Self-connections (pre == post) в proofread-таблице отсутствуют** (0). Этот вопрос оставался открытым после чтения источников.
4. **616 нейронов изолированы** (нет ни одной связи); у 1,250 нет исходящих, у 2,165 нет входящих.
5. **Граф неполон со стороны входов.** У медианного нейрона только **52 %** его пресинаптических синапсов ведут к
   proofread-нейронам (p5 24 %, p95 78 %). Причина: постсинаптические сайты прикреплены к нейронам лишь на 44.7 %.
   Со стороны входов, наоборот, **93.7 %** (медиана) постсинапсов нейрона приходят от proofread-нейронов.
   **[вывод]** Выходы нейронов в графе систематически недоучтены примерно вдвое.
6. **Слабые связи преобладают по числу, но не по массе:**

   | порог | пар | доля пар | синапсов | доля синапсов |
   |---|---:|---:|---:|---:|
   | ≥ 1 | 15,091,983 | 100 % | 54,492,922 | 100 % |
   | ≥ 2 | 7,595,967 | 50.3 % | 46,996,906 | 86.2 % |
   | ≥ 3 | 4,916,231 | 32.6 % | 41,637,434 | 76.4 % |
   | ≥ 5 | 2,700,513 | 17.9 % | 34,153,566 | 62.7 % |
   | ≥ 10 | 1,066,822 | 7.1 % | 23,664,861 | 43.4 % |

   Половина пар соединена **одним** синапсом. Синапсов на пару: среднее 3.61, медиана 2, p99 32, максимум 2,405.
7. **Больше всего синапсов в зрительной системе:** ME_R 8.82 M, ME_L 7.71 M, LO_R 3.88 M, LO_L 3.79 M,
   GNG 2.71 M, AVLP_R 2.00 M, LOP_R 1.90 M, AVLP_L 1.51 M.
8. **Асимметрия lamina:** LA_L 169,170 синапсов против LA_R 273,732. Это согласуется с частичным повреждением
   левой lamina, о котором пишут авторы (Dorkenwald 2024). Связь с повреждением — вывод, не проверка.

## 8. Воспроизведение

```bash
make setup
.venv/bin/biobrain download     # проверка md5 / git blob SHA-1, sha256 → lock
.venv/bin/biobrain preprocess
.venv/bin/biobrain validate     # должен дать PASS 38 / FAIL 0 / WARN 3 / INFO 13
```

Сборка детерминирована: повторный preprocess даёт те же sha256 массивов (тест `test_manifest_checksums_and_rebuild_is_deterministic`).
