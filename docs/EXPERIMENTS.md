# Эксперименты: конвенции и протокол

В Milestone 1 экспериментов с обучением нет — только измерения данных. Этот документ фиксирует правила
**до** первых экспериментов, чтобы результат нельзя было «подогнать» задним числом.

## Запись эксперимента

Каждый эксперимент — два файла:

- `experiments/exp_NNNNNN.yaml` — что запускаем (пишется до запуска, после запуска не меняется);
- `results/exp_NNNNNN.json` — что получилось.

Обязательные поля результата: `experiment_id`, `parent_experiment` (если есть), `git_commit` + `git_dirty`,
`dataset` + sha256 манифеста processed store, `seed` (все seed-ы), полная конфигурация, `timestamp_utc`,
hardware (`runinfo`), метрики (ниже), `result` (pass/fail критерия, объявленного в YAML), `notes`.
Эксперимент с `git_dirty: true` не считается воспроизводимым и не идёт в `RESULTS.md`.

Когда экспериментов станет больше ~20 — локальный SQLite-реестр (`experiments/registry.sqlite`) с теми же полями
и ссылками parent → child (ancestry для эволюционных экспериментов). Никакой серверной инфраструктуры.

## Метрики (раздел 21 постановки)

Качество: accuracy, loss, число обучающих примеров, скорость обучения (примеры до порога).
Ресурсы: inference/training latency, wall-clock, RAM peak и steady, CPU/GPU utilization.
Структура и активность: нейроны, рёбра, активные нейроны, спайки, **synaptic operations** (с разделением на
сложения и умножения), обновления состояния нейронов, чтения/записи памяти, объём включая индексы sparse-формата.

**Энергия:** только как (а) явно помеченная оценка — формула, константа, её источник, диапазон чувствительности;
или (б) инструментальное измерение с указанием границы измерения и idle/dynamic мощности. Оценку никогда не
называем измерением. Табличные константы (например, 0.9 pJ на сложение при 45 nm) — это не измерение SNN.

## Протокол сравнения топологий (Milestone 4 и далее)

Основано на разборе литературы (`docs/RESEARCH.md`, раздел «Предшествующие работы»): известные «преимущества
коннектома» чаще всего исчезали при строгих контролях.

1. **Заморозить определение графа** до экспериментов: порог синапсов, источник и правило знака, типы рёбер. Один и тот же для всех условий.
2. **Лестница нулевых моделей**, отчёт о ступени, на которой преимущество пропадает: ER (те же N и E) → сохранение in/out-степеней → + reciprocity → + in/out strength → neuropil-block / cell-type-block shuffle.
3. **Разделять топологию и веса:** перемешивание весов на фиксированной топологии; rewiring, переносящий веса; rewiring с сохранением strength.
4. **Сохранять знак каждого нейрона (Dale) и E/I-состав** во всех контролях; отдельный контроль — перемешивание знаков при том же E/I.
5. **Одинаковые входные и выходные нейроны** (идентичность и количество) во всех условиях.
6. **Нормировка спектрального радиуса не нейтральна:** публиковать сырой радиус, коэффициент нормировки и итоговый масштаб весов; добавить условия, выровненные по масштабу весов и по частоте спайков.
7. **Одинаковая инициализация**, не зависящая от топологии; одинаковая начальная активность.
8. **Одинаковый бюджет подбора гиперпараметров**, кривые «лучший результат vs бюджет» и устойчивость к гиперпараметрам, а не только лучший прогон.
9. **Много seed-ов × много экземпляров null-модели**; отчёт — размер эффекта, P(коннектом > null) с интервалом. p-value на полу перестановочного теста — не размер эффекта.
10. **Результаты по каждой задаче**, не только среднее.
11. **Pruning (H2):** сравнивать со случайным pruning при той же разреженности по популяциям, magnitude pruning, переобучением маски с новой инициализации, перемешиванием оставшихся синапсов внутри популяции; полные кривые «разреженность — качество».
12. **Эффективность (H3):** synaptic operations, обновления нейронов, память — при одинаковом качестве и одинаковом формате хранения для всех условий.

Критерий успеха/провала каждого эксперимента объявляется в YAML **до** запуска.
