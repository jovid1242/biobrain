# Допущения

Три разных вида утверждений держим раздельно:

- **A. OBSERVED DATA** — что содержит релиз (со ссылкой на источник или на проверку в `results/`).
- **B. PROCESSING CHOICES** — наши технические решения при обработке. Это не биология; каждое можно поменять и перезапустить.
- **C. SIMULATION ASSUMPTIONS** — то, чего коннектом не знает. В Milestone 1 модели нет, поэтому раздел пока
  содержит только список открытых вопросов, а не принятые допущения.

Если утверждение нельзя отнести к A, оно не может звучать как факт.

## B. Processing choices

| # | решение | альтернатива | где |
|---|---|---|---|
| B1 | **Ребро** = упорядоченная пара нейронов (pre, post) с ≥ 1 синапсом в любом neuropil; вес = сумма `syn_count` по строкам пары | держать ребро на уровне (pre, post, neuropil) | `preprocess` |
| B2 | Вероятности нейромедиатора ребра = среднее по строкам, взвешенное числом синапсов; хранятся как uint8 (`rint(255·p)`, ошибка ≤ 0.002) | float32 на 6 классов (×4 памяти) | `preprocess` |
| B3 | Self-connections (pre == post) **сохраняются** в store как наблюдение и **исключаются** из всех графовых статистик | удалять на этапе preprocess | `Graph.from_connectome` |
| B4 | Для анализа используются аннотации flywire_annotations **v3.1.0**; v2.1.0 — только чтобы сверить с числами статей 2024 года | Codex (смесь источников, требует логин) | `catalog` |
| B5 | Два порога графа: ≥ 1 синапс (всё наблюдаемое) и ≥ 5 (порог Dorkenwald 2024 и Lin 2024, делает сравнение возможным) | развёртка порогов — позже | `analyze` |
| B6 | **Home neuropil** нейрона = neuropil с наибольшим числом его пресинапсов (все партнёры); без пресинапсов — по постсинапсам. Повторяет правило neuropil-блоков Lin 2024 | по постсинапсам; по сумме pre+post | `analysis.regions` |
| B7 | Clustering считается на **простом неориентированном** представлении (как `global_clustering` в graph-tool у Lin 2024) | ориентированные варианты clustering | `stats.clustering` |
| B8 | Длины путей оцениваются BFS из случайных источников (по умолчанию 200) внутри гигантской SCC (ориентированно) и WCC (неориентированно) | точный all-pairs (N² ≈ 1.9·10¹⁰ пар) | `stats.path_lengths` |
| B9 | Degree-preserving null = перестановки Maslov–Sneppen (igraph `rewire`, 10 попыток на ребро, простой граф), сохраняются in- и out-степень каждого узла; по умолчанию 5 выборок (у Lin 2024 было 100, поэтому z-оценки ориентировочные) | switch-and-hold / больше выборок | `graph.degree_preserving_null` |
| B10 | Сообщества: Leiden по modularity (resolution 1) на неориентированном графе с весом «синапсы в обе стороны»; итерации до прироста < 1e-4 или лимита времени | CPM, другие разрешения, ориентированная modularity | `stats.leiden` |
| B11 | Betweenness оценивается алгоритмом Brandes из k случайных источников с масштабом n/k; две независимые выборки, стабильность top-100 публикуется | точный расчёт O(N·E) | `stats.sampled_betweenness` |
| B12 | Rich-club cut-off: минимальная степень k, начиная с которой нормированный коэффициент > 1.01 при всех бо́льших k (N_k ≥ 10) | порог 1.01 взят у Lin 2024; правило выбора k — наше | `analyzer.null_summary` |

## C. Simulation assumptions (открыто; до Milestone 2 ничего не принято)

Коннектом **не определяет** следующее, а любой SNN этого потребует. Каждый пункт в будущем станет явным
допущением, проверяемым на чувствительность:

- знак и сила синапса (вес ≠ число синапсов; глутамат в мухе бывает тормозным; ошибки предсказания нейромедиатора, особенно у редких классов);
- модель нейрона, пороги, постоянные времени, рефрактерность, спайковый vs градуальный нейрон;
- задержки проведения;
- электрические синапсы, нейромодуляция, нейропептиды, внутреннее состояние;
- правила пластичности.

Для справки (не принято): Shiu et al. 2024 (LIF всего мозга FlyWire) подобрали один свободный параметр
(вес синапса), остальные параметры взяты из литературы как общие. Подробнее — `docs/RESEARCH.md`.

## D. Гипотезы (не факты)

- H1–H3 из постановки проекта — это гипотезы, которые эксперимент может опровергнуть.
- «Модуль/сообщество = функциональный блок» — **гипотеза**; сообщества Leiden описывают только связность.
- «Узел с высокой betweenness = узкое место обработки» — **гипотеза**; это структурная метрика кратчайших путей.
